Stream DZ 3.0 - Android TV (Kotlin / Compose)

1) أنشئ مستودعاً جديداً على GitHub، وارفع كل ملفات هذا المجلد كما هي (بدون مجلدات).
2) Add file > Create new file واكتب الاسم:   .github/workflows/build.yml
   والصق محتوى build.yml.txt ثم Commit.
3) افتح Actions وانتظر العلامة الخضراء، ثم حمّل StreamDZ-apk من Artifacts.

إذا فشل البناء: أرسل صورة للسطور الحمراء في الخطوة الفاشلة.
